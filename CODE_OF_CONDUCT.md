# Code of conduct

noor-frame is built by and for families of many backgrounds. We want everyone who
takes part, whether they report a bug, write code or ask a question, to be
treated with respect.

## Our standards

**Do:**

- be kind, patient and welcoming, especially to newcomers;
- assume good intent, and ask before assuming;
- give and accept constructive feedback about the work, not the person;
- respect differences of opinion, practice and *madhhab*. This project makes
  choices, like calculation methods and translations, configurable for that
  reason.

**Don't:**

- harass, insult or demean anyone;
- make sectarian, racist, sexist or other discriminatory remarks;
- start religious arguments or debate rulings in project spaces;
- make sexual comments or advances;
- publish anyone's private information without permission;
- do anything else a reasonable person would consider inappropriate here.

## Scope

This applies in all project spaces: issues, pull requests, discussions and
reviews. It also applies when someone represents the project elsewhere.

## Reporting and enforcement

Report unacceptable behaviour privately to the maintainers through
[GitHub](https://github.com/rosman21/noor-frame/security/advisories/new),
choosing **Report a vulnerability** and noting that it's a conduct report.
Or contact a maintainer directly through their GitHub profile. Reports are kept
confidential.

Maintainers: enable **Private vulnerability reporting** in the repository's GitHub
**Settings → Security** so contributors can use the private reporting link.

Maintainers may edit or remove contributions, and may warn, suspend or ban
anyone whose behaviour breaks this code, in proportion to what happened.

This code is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
